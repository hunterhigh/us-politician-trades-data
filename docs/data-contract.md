# 数据契约

有效交付范围与九项限制见 [status.md](status.md)。本页定义产品事实、资格与消费边界；规范字段校验以`backend/src/unison_snapshot/builder.py`、`public_repo.py`、`fact_policy/`及`contract/`为可执行依据。

## 事实与身份

- 按官方披露行展示、计数。同资产不同账户分别保留，显示账户标题；不把账户合并成一笔“实际交易”。
- House、Senate与OGE/白宫保留来源、报告、原件URL及稳定行ID。可靠官方归属足以确定申报人，不另设签名字形门槛。
- 行情代码无法唯一匹配时，记录照常发布，ticker为空并显示“未匹配”。有来源及历史审计证明的ticker绑定不再依赖当前活跃SIP资格；当前行情名称、上市状态或身份变化只隔离新映射建议，不阻断整批。原始披露与来源完整性仍按既有规则验证。
- 发布数与本次重新确认数分别核对。未获证据的字段修订建议隔离；历史正式对象逐字段完整不变时可保留并列明缺口，不把保留项冒充本次重新确认，也不以此接收未知新事实或旧解析回退。
- 不猜日期、金额、owner或制造冗余正式ID；不将demo/simulated改标正式。正常事实为`official_matched`，不设逐条人工复核门禁。
- 允许有原件依据的旧事实纠错、修订、精确副本去重及唯一映射重编号。正常发布必须证明旧/新完整对象和前件关系；无法解释的消失或变化阻断相关发布。
- Senate年报Part4b、House Schedule B、OGE Part7保留独立披露行。跨报疑似重合只提示关系；已证明的副本、修订按来源规则处理，不按相同资产名称自动合并。

## 日期、归属与金额

申报人签字、机构接收、机构审核、OGE认证、修订签字和目录收录日期各有角色，不能互相替代。观察到日期不等于获得资格；缺必要日期按来源规则隔离。修订或前件缺失时保留原事实，不能以新件覆盖未知关系。

六列表未说明owner时可为`Undisclosed`；House新解析纸表在原件确实留空时同样适用。读不清、冲突不等于留空；不能扩展为House电子表或年报的默认值。旧owner纠正必须保留逐字段差异和证据。

开口金额不进入发布数组，列入 known_gaps。交易 amount_high 或持仓 value_high 为 null 的记录，review 保留原阈值、比较关系和未知上限，不补上限、不改为 0。known_gaps 按交易／持仓、人物、报告和披露阈值分别计数，使用现有数据边界说明展示；发布数组只含有限金额，并在发布前检查。

资格不因开口金额本身隔离；其他原因继续隔离。未获资格的开口金额观察在数据边界说明中列明报告、阈值、行数和剩余原因，不冒充合格交易；金额未读出不当作开口金额。

完整可靠持仓章节仅因官方明确价值未定形成缺口时，按已批准的House/OGE范围展示已知项并提示“部分报告”。有限区间合计不是完整总资产，不与旧报告混算；不放宽缺页、未读、归属冲突。缺少可核验行情的价格或收益保留null；七个早于可验证行情的事件收益显示“—”。

## 修正与缓存

统一修正位于`backend/data/corrections/<用途>/<document_id>.json`，schema为`source-correction/v1`。动作限于`set_field`、`set_report`、`add_row`、`drop_row`、`quarantine`、`relate`。每次写入断言原值及字段存在性；新增断言目标不存在，删除/隔离断言完整原对象，关系携带另一原件的身份和哈希。

适配层负责来源身份、真实目标行、格式及原件证据；公共引擎原子应用，失败不部分改写输入。已迁移实例额外绑定行库存、物理位置、完整输入/输出或独立原件重放。数据文件不能授权正常资格规则拒绝的事实变化。修正迁移和对应专用代码删除在同一PR完成。

Burrows分类修正仅改变原件已证明的Bond误判，保留ID；owner变化另有独立规则。封面日期观察保持原角色，修订签字不作申报日期。旧v2封面日期观察只适用于相同原件哈希、日期角色和前置旧值均匹配的当前原生解析；不跨原件或套用到通用及其他解析器。

OCR缓存以原件/页面内容及格式版本绑定，OCR引擎保留为来源信息；改变修正不触发重复OCR。旧缓存必须满足当前原件及修正断言。源哈希或断言变化时拒绝套用，记录阻塞并告警，不能静默生成“相似”事实。

## 快照与可见边界

manifest固定board、分片索引、处理器及market提交。读取先固定一个提交，逐项验证哈希和大小；人物/证券按需读取，同一结果不混不同提交。`universe_complete=false`不声明全美国政客或全历史覆盖。

`source_health`描述该快照的来源状态。独立health入口区分采集尝试与合格候选水位。`disclosure_status`为内容寻址的报告处理状态，绑定同一snapshot与board。

各来源使用各自真实的合格`data_cutoff_at`，不再取共同最小截止日、不裁掉较新来源的事实。新快照以`source_cutoff_policy=per_source/v1`标明该语义；顶层`data_cutoff_at`取最新来源水位，仅作为30/90天等统计窗口的参考时间，不表示所有来源都完整覆盖到该时刻。每条披露不得晚于所属来源的截止时间；manifest的`source_health`分别记录截止时间及布尔`stale`、`unavailable`。旧快照保持原有读取和回退兼容。

House、OGE的采集与合格水位均不得超过48小时。Senate可以保留过期的旧事实发布，期限由`SENATE_MAX_STALE_DAYS`配置，默认30天；超过即全站停发，缺失水位、未授权采集及内容完整性失败仍然阻断。Senate过期达到20天额外提醒一次，来源告警保持打开；真实发布恢复后关闭发布错过窗口告警。过期时报告页脚和Senate相关人物页显示真实截止日期、官方站点暂时无法访问及统计部分不完整。正常采集目录必须覆盖上次成功以来全部区间，待补齐后自动恢复正常状态。

状态记录的`bound_person_ids`由同一board的官方报告事实关联生成，`person_binding_basis=published_fact_report_binding`；不是从申报姓名或未验证人物字段猜测。它支持逐报告回核人物缺口计数；旧状态缺此字段时不补猜。

`known_gaps`是`known-gaps/v2`来源库存摘要：部分/隔离/未评估/需申请的报告记录数、隔离行数、行数未知的记录数、申报日期区间、原因及限制。条数未知不能填成完整覆盖。人物只按已有正式事实的同一官方报告URL或已验证报告绑定识别，不按名字或来源推断。`person_unparsed_report_counts`按人物及来源内官方报告身份去重，统计仍有上述缺口的报告（含部分解析）。人物页显示“该人有N份披露未解析”；无法绑定的保留来源整体统计。摘要不改变事实、原ID或snapshot身份，不得无声消失。兼容v1摘要及旧快照；没有人物计数时不声称为0。

manifest预算16KiB；摘要较大时，known_gaps使用known-gaps-reference/v1引用同一固定提交的status/<sha256>.json（上限256KiB），含哈希和字节数。客户端校验后还原完整摘要；不截断人物、原因或未知信息。报告页脚及人物页使用正常公开读取、处理和渲染入口展示摘要。

完整board上限64MiB，人物/证券分片保持16MiB；生产和公开读取使用同一预算，超限或哈希不符仍拒绝。House PTR、House年报、OGE、白宫及Senate共用`parser_replay.ParserTarget`判断存量解析是否可复用：原件绑定、当前源格式所选版本及必需证明均须满足；旧版本成功或失败均重新进入正常受控解析入口，当前失败只在同一版本内终结，路由解析器任一版本改变会重启对应失败。OGE旧版缺失完整单元格证明的缓存不再作为当前结果，也不以保留正式旧结果代替重跑；归档历史目录也纳入解析，当前解析未闭合时阻断组装。House年报逐批持久化，全部完成后组装；持仓原文证明不会自动扩大Schedule B交易接入范围。

部分持仓覆盖证据较大时，manifest的holding_report_coverage使用holding-report-coverage-reference/v1引用同一提交的status/<sha256>.json（上限4MiB），校验长度及哈希后恢复完整数组；不截断报告、行ID或未定值说明，兼容旧版内嵌数组。
