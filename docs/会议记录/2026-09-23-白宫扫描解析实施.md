# 2026-09-23 白宫扫描解析实施

## 本次目标

在不放宽现有资格门禁、不修改 `review-input/`、不使用付费 OCR、也不制造日期或身份事实的前提下，为白宫公开扫描 PDF 增加可重复的 OCR 与表格几何解析，并把已经通过既有自动资格规则的白宫年报子集发布到生产。

## 已完成

- 共享 OCR 几何层使用本机和 GitHub Actions 可安装的 Tesseract，输出逐词文本、置信度和原 PDF 坐标；OCR TSV 按制表符严格解析，避免引号字符吞并后续行。
- 278e 扫描解析保留封面、章节、页码、行号、原始单元格和置信度证据。超过 100 页的报告按 25 页不可变分片执行，检查点绑定原件 SHA-256、来源 URL、解析器版本和 Tesseract 引擎；只有全部源页齐备后才合并。
- 278-T 先尝试原生文本，扫描件按 200/300 DPI 的完整记录数择优；各页由表头动态确定列边界，几何行序与打印行号分开保存，低置信度和不完整字段进入隔离。
- v5 续页完整性与重复行审计修复后，目标测试 14 项、后端完整回归实际运行 368 项并通过；差异空白检查通过。

## 期间语义与后续维护

万斯原件封面写明 `Annual Report` 与 `Year 2025`，用户确认扫描版字段规范映射为 `report_period_end=2025-12-31`。扫描解析器按该决定重建检查点；已经生产验证的 Integrity 电子版映射保持不变。后续增量继续复用同一版本、原件哈希、来源 URL 和 Tesseract 引擎绑定；任何解析器升级必须使对应检查点失效重建。报告级签名、机构、身份、行号、置信度、修订和重复门禁继续决定是否进入候选，完成 OCR 不等于取得生产资格。
