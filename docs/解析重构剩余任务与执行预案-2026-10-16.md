# 解析重构交付定义

以下35项保留原交付范围，按需核对，不是每次开工的必读清单；已完成工程直接复用。当前安排和决定仅见[目标](当前目标与优先级.md)、[状态](实现状态与下一步.md)，固定范围见[执行输入](解析重构执行输入-2026-10-16.json)。

阶段顺序：格式能力/实际消费 → T22确认范围 → T23统一重放 → T24–T27差异、页面、定向核验及自动/恢复 → T28–T30切换、清理、交付。一般技术调整自主处理，改变产品/范围/授权才讨论；局部失败只暂停依赖它的工作。

| 任务 | 具体行动 | 交付要求 |
|---|---|---|
| T00 | 固定现有代码、官方原件与HTML输入范围。 | 输入版本和已知/未知范围可定位。 |
| T01 | 复用已完成工程，定位真正待改的入口。 | 不重建已有账本、候选或发布器。 |
| T02 | 连接页/格/字段、披露行、资格和报告状态。 | 同版原件可回溯，未知与未披露分开。 |
| T03 | 准备既有固定格式的开发与独立检查样本。 | 已知答案、负例和未覆盖范围明确；不靠无界采集凑样本。 |
| T04 | 完成OGE 2024扫描交易表及行格定位。 | 相关原件能定位或明确报告能力缺口，非交易区不误入。 |
| T05 | 修资产词序、跨列、换行与截断读取。 | 保留可回溯的披露原文，不用证券字典猜名称。 |
| T06 | 接入方向、日期、金额、档位和行号读取。 | 标准行正常消费，冲突保留全部阻断原因。 |
| T07 | 区分数据/标题/空白/备注/未知并连接续行。 | 物理格、逻辑行和处置守恒，标题不计交易。 |
| T08 | 支持OGE/白宫其余原生、坏文字层、旧版及扫描278-T。 | 按来源证据路由，各格式结果接现有行账。 |
| T09 | 完成House纸PTR表格、字段和来源关系。 | 正常行经现有资格消费，未知和非数据区正确处置。 |
| T10 | 回归House电子PTR布局、字段与官方修订标识。 | 旧合格事实保持，新旧格式均接同一结果链。 |
| T11 | 完成Senate纸PTR账户、日期、勾选及未知槽处理。 | 不同账户披露分别计数，标题作用域和未知有据。 |
| T12 | 连接Senate电子PTR、目录身份和修订链。 | 已合格事实及修订结果不退步，不重建采集。 |
| T13A | 解析House年报Schedule B交易及跨报关系。 | 独立披露按获批口径消费，副本/修订有据处理。 |
| T13B | 解析House Schedule A父子资产、备注及官方代码。 | 层级/覆盖明确，部分持仓按已批准口径展示。 |
| T14 | 分别解析Senate年报交易与持仓章节。 | 章节不串表，年度独立披露及跨报标注正确。 |
| T15A | 绑定OGE/白宫年报封面身份、报告期和日期角色。 | 可靠官方归属有效；申报、审核、认证等日期不互代。 |
| T15B | 解析278e Part7交易及与278-T的关系。 | 独立披露按获批口径消费，非交易章节不混入。 |
| T15C | 补齐278e Parts2/5/6持仓及账户关系。 | 持仓/收入/交易分开，保留版本、覆盖和未知值。 |
| T16 | 统一官方来源、人物、原件版本及日期角色绑定。 | 不加签名字形门槛，不强合身份冲突。 |
| T17 | 处理内容副本、修订与跨源/跨报关系。 | 精确副本去重，唯一替代链可解释；三源年度披露依现行决定。 |
| T18 | 落实已批准的有限/开口金额页面及汇总规则。 | 不造上限，交易与持仓均分开展示、统计。 |
| T19 | 落实已批准的部分年报持仓规则。 | 完整可靠章节的官方价值未定提示缺口，不混报告或放宽未读。 |
| T20 | 统一稳定正式ID及内部迁移对应。 | 无双轨正式记录，纠错/重编号有唯一来源映射。 |
| T21 | 将格式结果接现有资格、候选和受控工作流。 | 固定输入自动处理，缓存版本可靠，不提前批量补数。 |
| T21S | 适配现有报告状态读取新旧格式结果。 | 身份/版本/计数与资格一致，未知不报零，不造第二套状态。 |
| T22 | 对固定范围检查格式、字段、关系和实际消费。 | 未支持项保持未完成，冻结可统一重放的版本。 |
| T23 | 对冻结原件范围统一重放完整链。 | 每个输入有结果或失败，中断可恢复，不扩成历史重采集。 |
| T24 | 比较新旧ID、字段、来源、报告及隔离差异。 | 每项变化有依据，净恢复计入所有阻断，状态与事实同版。 |
| T25 | 按最新HTML验收页面矩阵。 | 窗口、人物/股票、金额、账户、链接、缺失及收益正确。 |
| T26 | 末端对剩余疑点做定向原件核验并局部重跑。 | 具体风险有处置；系统错误回修格式，不手工逐行补事实。 |
| T27 | 演练正常自动入口、重复、失败阻断及回退恢复。 | 无需手拼产物，无半包发布；状态/事实同版，恢复可行。 |
| T28 | 通过既有受控发布并回读正式版本。 | 来源、差异和页面一致，异常可按已验证路径回退。 |
| T29 | 清除稳定新版不再需要的代码及产物。 | 依据实际用途/引用处理，保留必要运行和恢复能力。 |
| T30 | 确认完整交付及剩余真实异常。 | 全部约定任务完成或有用户接受的延期，不以PR/测试数结案。 |
