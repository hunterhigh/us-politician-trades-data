## 原有设计的核心要求

| 环节 | 输出及边界 |
|---|---|
| R0 原件与格式 | 绑定官方目录、URL、文件哈希、页数、人物线索及格式。OGE/白宫同内容的来源出现分别保留，再判断事实关系。未知格式不报零交易。 |
| R1 页与章节 | 依据封面、表头、章节、列结构及终点定位交易/持仓/备注。文字层质量、坐标系、解析版本和未观察区域可追溯。 |
| R2 版面片段 | 原生PDF用词位/表线、HTML用DOM、扫描用已验证的版式证据发现片段；不要求日期/金额先读对才承认行存在。 |
| R3 字段观察 | 保留资产、owner、方向、日期、金额、编号、备注的原文、位置、哈希、引擎和转换依据。多次观察冲突保留，不能用邻行填值。 |
| R4 语义解释 | 官方代码、金额档及报告上下文用于解释；交易/申报/通知/审核日期分别处理。未披露、未读、价值未定、有限和开口金额分别表达。 |
| R5 覆盖对账 | 页/格、非数据处置、片段与逻辑行、资格结果分别核对；允许多片段对应一行，未知覆盖不当作字段隔离数。 |
| R6 事实关系与候选 | 复用现有身份、资格、修订和候选工程。精确副本/修订有依据；独立披露及跨报疑似重合按已批准口径消费。 |
| R7 页面及末端核验 | 先构建候选、核对旧事实差异和最新HTML，再定向回看剩余原件疑点；通过既有受控发布和恢复路径交付。 |

最小关系为document_manifest、section_coverage、physical_slot、cell_observation、slot_record_relation、row_disposition、fact_relation。复用已实现接口；观察位置与正式ID分开，版本迁移有映射，不保留冗余正式记录。

## 降低隔离的独立工作

| 工作项 | 处理原则 |
|---|---|
| Q1 通知日期 | 通知缺失或仅通知顺序异常时保留提示，不单凭此阻断其他完整交易；实际交易日/申报日问题仍单独判断。 |
| Q2 来源身份 | 依据可靠官方目录及原件绑定归属，签名字形不单独阻断；日期角色不互代。 |
| Q3 持仓隔离传播 | 叶子问题不无理由扩成整报隔离；部分持仓按现行获批条件处理，不把潜在上界当实际恢复。 |
| Q4 重复和修订 | 使用报告、版本、原行及事实关系，不凭同名同日或模糊资产名合并。 |
| Q5 金额/方向/日期 | 依原格和官方档位解释；不编造上限、补字符或猜日期。 |
| Q6 行号与完整性 | 区分OCR误号、官方重复号和不同披露行；打印序号不能独立证明完整性。 |
| Q7 官方非有限值 | 按已批准的有限/开口分开展示及官方价值未定规则处理；未读不伪装成合法缺失。 |

实际净恢复必须同时满足该行所有必要条件；命中或修正一个原因不等于新增可展示记录。格式实验、固定样本消费、生产迁移分别判断。

官方原件和机器证据留在现有归档/产物中，按需引用，不复制为逐轮人工日志。复杂失败先定位坐标、来源、读取、解释或关系中的实际断点，再用能区分假设的实验选择路线。
