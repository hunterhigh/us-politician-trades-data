## 必须保留的协作边界

- 不修改 `review-input` 的交接基线；只报告实际运行的交接包测试和本项目契约测试。
- 正式代理拒绝合成快照；本地 demo 不接入正式 main。
- `published/<SHA>` 用于证明“技术发布过”，不表示数据授权已成立；官方 raw 只进入 `evidence`，不得混入 `main`，密钥不得写入任何 Git ref。
- 目前按全部输入建 board，没有任意大规模截断/分页；触发大小阈值时应先调整契约和窗口，再恢复发布。
- snapshot_id 包含业务截止时间和展示配置。健康检查时间单独变化不影响它；generated_at 单独变化不创建无意义提交。
