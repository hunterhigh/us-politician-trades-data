## 已知限制

1. 扫描件字符冲突、错字缺字：隔离受影响行，保留原件入口。
2. 复杂边框、贴边笔迹：隔离无法可靠识别的行。
3. 手写/连笔日期：缺必要日期时整报隔离，不推断日期。
4. 扫描续行、跨页归属：无法唯一关联时隔离。
5. 扫描无漏行证明不足：保持 partial，不宣称完整。
6. 扫描修订、缺失前件：保留旧事实，隔离新报告。
7. 需申请的 OGE 278-T：request_required，v1 不申请。
8. 历史 ID 通用重编号：不做，修正保留原 ID。
9. Paddle/TrOCR 等未采用实验：退出 v1，清理时退役；不再运行。

隔离不是删除，进入报告状态及 known_gaps；旧事实无依据不得消失。不猜日期、金额、owner，不将 demo 改标正式。既有有效产品语义保留。
