## 已知限制

1. 扫描字符冲突、错字缺字：行隔离。
2. 复杂边框、贴边笔迹：无法可靠识别则隔离。
3. 手写/连笔日期：缺必要日期整报隔离，不推断。
4. 扫描续行、跨页归属：不能唯一关联则隔离。
5. 扫描无漏行证明不足：保持 partial。
6. 扫描修订、缺失前件：保旧，隔离新报告。
7. 需申请的 OGE 278-T：request_required，v1不申请。
8. 历史 ID 通用重编号：不做，沿用原 ID。
9. Paddle/TrOCR 未采用实验：退出v1，清理时退役，不再运行。
