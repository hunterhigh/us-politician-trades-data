## 已确认的产品原则

1. 对方前端是验收目标。后端、数据布局和读取层适配前端，不要求前端为当前后台骨架删减功能。
2. 取消全量逐条人工复核、具名复核者和逐条人工批准门禁。已有人工复核命令和模板降为异常调查工具，不再阻止符合自动规则的标准记录发布。
3. 标准记录由确定性自动规则晋级。解析不确定、OCR置信不足、身份冲突、修订关系不明、金额语义无法表示或证据不闭合的记录进入隔离队列；隔离记录不阻塞其他合格记录。
4. 人工抽样审计可以用于评估解析质量，但不是每条记录的生产前置条件。来源用途和行情再分发许可仍属于项目级发布条件。
5. 不伪造缺失字段、价格、收益或覆盖范围。无法支持的数据必须明确标记缺失、隔离或不覆盖。
6. 完整候选快照先通过前端验收，再移动正式 `main`；生产发布保留固定 commit、内容哈希、发布标签和回退能力。

## 自动晋级规则

一条披露记录只有同时满足以下条件，才能自动进入候选事实：

- 来自约定的官方来源，并能定位到已归档原件、来源 URL 和 SHA-256；
- 解析器版本固定，文件版式属于已通过黄金样本验证的类型；
- 人物由官方稳定标识或无歧义规则确定，不能只依赖姓名猜测；
- 日期、交易类型、资产、金额语义和证券标识通过 schema 与业务校验；
- 修订、撤回和 amended 关系能够由确定性规则建立；无法确定时隔离；
- 去重、外键、证据引用和内容哈希检查通过；
- 没有静默丢行、截断或用默认值掩盖解析失败。
