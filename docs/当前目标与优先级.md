# 当前目标与优先级

## 目标与当前主线

完成已批准的35项解析重构、11类输入，使官方披露行经现有资格、候选、报告状态及消费链服务最新HTML。复用现有工程，正常行自动处理，异常有去向。

2026-10-22用户调整当前工作方式：先集中收集技术卡点，按共同根因、影响和依赖研究解决路线，将关键技术判断放在计划阶段完成；随后要求攻克这些问题。当前按[技术问题与解决计划](解析重构技术问题与解决计划.md)组织调查、对照实验和已证实方法的实现，不继续遇到一个问题就立即修改一个问题。原聊天不再作为必读接续入口。

计划阶段承担必要的只读调查和用于区分假设的小实验，明确方法、适用范围、验收及失败后的处置；执行阶段落实已确定的代码、接入和部署步骤。实验推翻假设或出现计划外关键未知时，返回计划修订，不由执行阶段临场扩展路线。普通实现细节仍由Codex负责，不转交用户作技术选择。

## 有效边界

- 最高前端基准为根AGENTS指定的最新HTML，旧方案冲突时以它及用户后续批准的产品口径为准。
- 原交付阶段顺序保持：T02–T22格式能力和固定样例消费，随后T23统一重放，T24–T27差异、HTML、末端定向核验及自动/恢复，T28–T30受控切换与清理交付。用户随后要求攻克已收集问题，授权按共同根因研究、实验，并落实已有依据的方案；先完成相应技术判断，再实现及验证，不增加例行审批流程。
- 当前不提前全量补数、重采集或切换生产。固定5页Paddle试验仍由用户暂停，不自行重试、轮询内存或关闭应用。
- 2026-10-23用户明确连笔日期先不处理：已核实当前未解决，本轮列为明确不解决、暂缓项，移出当前攻克和方法比较安排；不继续日期识别模型、分割或专为该识别服务的定位实验，用户明确恢复后再处理。既有已验证蓝墨日期能力保留。受影响报告继续如实保留日期未知及资格阻断，不替换日期、不算解决；其他问题继续推进。
- 普通范围内技术选择由Codex承担；改变产品承诺、范围、显著费用或用户暂停决定时才讨论。

## 已批准产品口径

- 按官方披露行计数；同资产不同账户分别保留并显示账户标题。可靠官方归属足以确定申报人，不另设签名字形门槛。不得猜日期、金额、owner或制造冗余正式ID。
- 七个早于可验证行情的事件收益保留null，页面显示“—”。
- 交易及持仓的有限金额与开口金额分开展示、汇总；开口保留阈值与未知上限，计入条数，在金额排名中单列，不伪造上界。
- 六列表未说明owner可显示Undisclosed；House新解析纸表原件确实留空时亦适用。读不清/冲突不是留空；不自动扩展到House电子表或年报默认值，旧正式owner纠正先列差异。
- 完整可靠持仓章节仅因官方明确价值未定形成缺口时，可展示已知项并提示部分报告。适用于已批准的House及OGE情形，不混报告、不冒充完整总额，不放宽缺页、未读或冲突。
- Senate年报Part4b、House Schedule B、OGE Part7按独立披露行展示、计数；跨报疑似重合标注，已证明的副本/修订仍去重。
- 允许有源依据的旧事实纠错与唯一映射重编号；无法解释的丢失或变化阻断相关发布。
