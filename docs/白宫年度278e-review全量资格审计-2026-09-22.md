## 重放与证据

固定 `review` 提交的根 tree 为 `8819daa3357cc2178fa9e8c454d97c0a6f2cb2d1`，覆盖文件 Git blob 为 `6c954e5cf1c74024e279bb53a6ef1e3b4bfd42c6`，官方索引页 SHA-256 为 `9df1a4315382feeb03e531bb52520400fd5862f76d2398fc29e84bd22c1c15f6`。每份逐报告输出包含原件 URL、PDF SHA、review 提取路径、年度、门禁原因和处置行数。

在本分支根目录运行（需要可读取该 GitHub 仓库的 `gh` 登录、Python 与 `pdfplumber`）：

```powershell
python backend/scripts/audit_whitehouse_annual_review.py --ref a3662291c15a005423edc49869c23d14d1b04705 --artifact-version 2 --workers 8 --reparse --output "$env:TEMP\whitehouse-annual-278e-audit.json"
```

重放器先校验 Git blob、归档 SHA 与 URL 的对应关系，再从白宫官方 URL 下载年度 PDF，逐份核对 SHA-256，用当前 v2 解析器重新提取并审计。实际运行结果：**95／95 官方 PDF 哈希相同，95／95 重提取与 review 保存结果逐字段一致，95／95 审计重现零份完整合格**。命令只读远端并将审计 JSON 写到指定输出路径，不更改 `review` 或生产五数组。

完整生产晋级还需稳定人物身份、修订关系、官方归档引用、交易去重、行情及五数组快照门禁；本审计没有替代这些步骤。
