## 1. 目标、基准和范围

本轮目标是让**现有已正式合格的数据无损进入可追溯、可复现、可隔离异常的新治理路径**，并生成与最新前端相符的完整快照。既有正式事实不能因为新的影子解析器未覆盖某种文档而消失。来源采集和解析的质量改进继续做，但不以全量历史 PDF 重新扫描、OCR 或重解析作为治理切流的默认前提。

| 工作线 | 本轮交付 | 与切流的关系 |
| --- | --- | --- |
| A. 治理迁移 | 固定旧候选、资格和来源证据的逐条绑定；统一账本与处置；确定性五数组投影；新旧差异、前端、发布和回滚门禁 | 本轮关键路径。旧合格记录可经已验证的旧抽取和资格结果迁移，不要求重跑 OCR。 |

## 3. 修订后的实施顺序与放行件

### G0 固定输入与迁移清单

在隔离工作树固定六个分支提交、生产 manifest、现有三个来源候选文件、review 抽取/资格产物、evidence 元数据、HTML 哈希和市场提交。生成旧正式五数组的机器可读清单：交易、持仓、人物按旧 ID 唯一，行情与来源健康按快照键和固定市场提交对账；每条事实列出来源、申报/人物、规范字段、证据引用、原资格规则及输入对象哈希。来源字节确未重新读到时标注 `archived_hash_not_reverified`。保持原始主工作区的既存未提交改动，不覆盖 `review-input/`。

### G1 统一旧事实与账本桥接

沿用已闭合的 9,742 条绑定，并将白宫 PTR 1,391、年报 6,759、其他 OGE 124 的固定旧抽取/候选对账纳入同一机器门禁。为 Senate 纸面旧候选 1 条建立来源绑定；若无法确认，保留在旧路径并作为该条阻断，不能从新投影静默删除。桥接记录必须区分 `legacy_qualified_binding` 与新解析产生的 `qualified` 观察值，记录原资格及证据链，不把旧结论冒充新 OCR 结果。跨文档重复/修订保持既有可信决议；新证据有冲突时逐条隔离并记录差异。

**G1 放行件：** 18,017/18,017 旧交易 ID 均有唯一的“迁移绑定、明确保留于旧路径、或有证据的修订/撤回”处置，且与正式快照的交易数和 ID 集合逐项对账；5,593 条旧持仓与 392 个人物也建立独立的来源/资格/ID 覆盖账，不被交易覆盖率代替。切流所需的新投影最终不得依赖“保留于旧路径”占位；该状态仅用于避免过早删除和定位阻断。所有新增影子行与旧数据分开计数。

### G2 确定性候选与前端投影

用桥接结果和现有来源资格规则生成完整五数组候选：人物、交易、持仓、行情与来源健康。复用原候选 builder 的人物、申报时间、持有人、证券、期权、修订和去重规则；ledger 只提供来源观察和证据，不能直接填充这些缺项。所有旧正式交易和持仓均按 ID/字段比较；允许的差异必须有单独决议和对应前端影响。未知 ticker/价格保持 `null`，收益不可计算保持 `null`。输出快照前检查唯一 ID、引用完整性、来源健康、数据截止和市场固定提交。

**G2 放行件：** 旧正式 ID 无静默减少、字段差异无未解释项，新增记录只来自独立通过资格的来源；最新 HTML 所用字段、页面和缺失值全部可表达。体积/重复数组优化只有在消费代码确认无兼容损失后再做，不占据切流关键路径。

### G3 只读影子、任务闭环与发布准备

在固定输入上重复构建，比较内容哈希、行处置、候选 ID/字段与五数组；核对手动、定时、失败重试的幂等和现有 writer lock。影子产物仅写隔离路径，不写生产 `main/market`。用最新 HTML 的真实处理器及浏览器核对 dashboard、search、person、ticker、来源状态、行情与“—”语义；旧交接材料只记录兼容影响。验收旧 `main/market` 固定提交可读、发布失败不移动指针、回退不依赖重新采集。

### G4 受控切流与观察

只有 G1–G3 的机器报告和实际验收均通过，才让现有唯一完整发布工作流读取新候选；发布前后分别固定和回读 `main/market`，保存对应标签和快照哈希。先保留旧候选构建和回滚入口，观察实际增量运行及差异；出现数据丢失、身份/来源错误、前端语义倒退或重复写入时，按固定已发布提交回退。切流后再讨论旧路径退役和 cron/传输优化。

## 4. 来源质量队列的处理规则

House 失败扫描件与漏行、Senate 纸面格位、OGE 年报 Part 7、OGE 85 条身份/重复异常、白宫 OCR 漂移等按来源、文件和记录单独立项。每项保存固定原件/抽取哈希、页/行/格证据、旧候选关系、处置原因和复核后的新规则。可证明的新事实经现有资格和去重门禁后增量进入候选；仍有歧义的事实继续隔离。不可用的实时来源或 OCR 环境不得触发对旧合格事实的撤回。若某项发现证明旧正式记录本身不可靠，则对该记录执行专项调查和有证据的修订决议，暂停它的迁移或发布；不以此推断全站迁移失败。
