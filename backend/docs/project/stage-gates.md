# 项目阶段门

## 允许开始开发

- 范围、成功标准和重要决定已经确认
- Git 与敏感配置边界存在
- 最低验证通过

## 允许内部试用

- 真实身份和权限边界已验证
- 测试数据与生产数据隔离
- 失败可被发现并有基本恢复路径

## 允许正式上线

- 同一版本先在非生产环境验证
- 正式发布可追溯且可以回退
- 发布后检查、费用和运行边界明确

当前 GitHub 生产骨架已上线：规范快照可回退，来源检查点可恢复，官方原件进入内容寻址证据分支，工作流受有界批量和超时约束。当前生产快照为 `bootstrap_empty`；真实事实将通过自动资格校验进入完整候选快照，异常进入隔离队列。逐条人工复核不再是门禁；完整行情和原前端验收仍是上线条件。

## 允许成为关键基础设施

- 恢复演练最近完成
- 权限、容量、降级和事故处理已审查
- 其他人能够恢复关键访问并接手
