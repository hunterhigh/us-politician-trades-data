# 项目阶段门

## 允许开始开发

- 范围、成功标准和重要决定已经确认
- Git 与敏感配置边界存在
- 最低验证通过

## 允许内部试用

- 真实身份和权限边界已验证
- 测试数据与生产数据隔离
- 失败可被发现并有基本恢复路径

## 允许正式上线

- 同一版本先在非生产环境验证
- 正式发布可追溯且可以回退
- 发布后检查、费用和运行边界明确

2026-09-21首发正式上线：`main`已发布非空五数组，`market`保存授权行情，来源检查点可恢复，官方原件进入内容寻址证据分支，异常进入隔离队列；完整候选和远端发布结果通过冻结前端验收。逐条人工复核不作为标准记录门禁。这里保留阶段门的通用条件，当前版本、覆盖边界和待完成的连续定时验证以项目根目录[实现状态与下一步](../../../docs/实现状态与下一步.md)为准。

## 允许成为关键基础设施

- 恢复演练最近完成
- 权限、容量、降级和事故处理已审查
- 其他人能够恢复关键访问并接手
